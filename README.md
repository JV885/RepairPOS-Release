## 🔄 Automatic In-App Updates
If you already have RepairPOS installed on your computer:
1. Launch the RepairPOS desktop application.
2. The application automatically checks `https://raw.githubusercontent.com/JV885/RepairPOS-Release/refs/heads/main/manifest.json`.
3. When `v3.1.0` is detected, click **"Download & Install Update"**.
4. The application automatically verifies the SHA-256 checksum, updates itself, and restarts while preserving your local database (`shop.db`).
